Critères d'arrêt immédiat

On interrompt la recette et on diagnostique avant de continuer si l'un de ces trois signaux apparaît : une donnée réelle disparaît sans qu'on l'ait demandé · un MAR autre que toi reçoit un email · une page reste blanche sans message d'erreur. Tout le reste se note et se poursuit.

P0Prérequis

À faire dans l'ordre. Ce ne sont pas des tests : c'est le filet.

  1. Sauvegarde du classeur maître. Fichier → Créer une copie, nommée SAUVEGARDE-AVANT-RECETTE-2026-08-01, rangée sur ton compte perso. Non négociable : la phase 10 supprime des onglets.
  2. Contrôle de version. admin.html → onglet Maintenance → 🔍 Diagnostic. Aucune ligne ne doit signaler de désynchronisation entre le dépôt et le déployé. Si une recopie manque, fais-la maintenant : sinon tu testeras un code différent de celui que je lis.
  3. État de départ, noté sur papier. Dans CONFIG : valeur de ANNEE_ACTIVE (attendu 2027) et de INDISPOS_ACTIVE. Dans le classeur : la liste des onglets présents. C'est ta référence pour le nettoyage final.
  4. Classeur d'archive. Ouvre-le et vérifie s'il contient déjà STATS_GARDES_2027. Si oui, note-le : la clôture l'écrasera sans prévenir.
  5. Emails. Tu confirmes que seule ton adresse est renseignée dans MEDECINS. Recompte-le une fois, ligne par ligne, avant la phase 10 : c'est le seul point où une erreur touche l'équipe.
  6. Console ouverte. F12 → onglet Console, gardée ouverte toute la séance. La moitié des anomalies s'y voient avant de se voir à l'écran. Note toute ligne rouge.
  7. Un seul onglet du portail ouvert, sauf quand un test demande explicitement le contraire.
  8. Rechargement forcé (Ctrl+Maj+R) sur chaque page au moment où tu l'ouvres pour la première fois.
